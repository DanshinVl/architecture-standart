# Список крупных задач по системам

Документ содержит перечень крупных задач для реализации решения,
описанного в ADR. Эти задачи используются для дальнейшего
планирования работ и формирования RoadMap.

---

# 1. Rate Management Service

## T1 — Проектирование сервиса ставок
Основная цель: подготовить архитектуру решения для централизованного управления ставками.

Задачи:
- анализ требований к управлению депозитными ставками
- проектирование модели данных ставок
- проектирование API для получения ставок
- подготовка архитектурной документации

---

## T2 — Разработка сервиса ставок
Основная цель: реализовать backend-сервис управления ставками.

Задачи:
- реализация бизнес-логики ставок
- реализация хранения ставок в базе данных
- реализация аудита изменений ставок
- реализация API для получения актуальных ставок

---

## T3 — Интерфейс управления ставками
Основная цель: предоставить сотрудникам бэк-офиса интерфейс для управления ставками.

Задачи:
- разработка пользовательского интерфейса
- редактирование ставок депозитов
- ввод специальных ставок
- согласование изменений ставок

---

# 2. Система кол-центра банка

## T4 — Интеграция с сервисом ставок
Основная цель: обеспечить получение актуальных ставок системой кол-центра.

Задачи:
- разработка интеграции с Rate Management API
- получение ставок по депозитным продуктам
- обработка ошибок интеграции

---

## T5 — Отображение ставок оператору
Основная цель: предоставить операторам кол-центра доступ к актуальным ставкам.

Задачи:
- доработка интерфейса оператора
- отображение ставок продуктов
- обеспечение удобного поиска ставок

---

# 3. Партнёрский кол-центр

## T6 — Разработка экспорта ставок
Основная цель: сформировать файл ставок для передачи партнёрскому кол-центру.

Задачи:
- разработка сервиса генерации файлов
- формирование файла ставок
- преобразование данных в согласованный формат

---

## T7 — Передача файлов партнёру
Основная цель: обеспечить регулярную передачу файлов со ставками партнёрскому кол-центру.

Задачи:
- настройка расписания выгрузки
- настройка хранения файлов
- организация операционного процесса передачи файлов

---

# 4. Запуск решения

## T8 — Тестирование решения
Основная цель: проверить корректность работы всех компонентов системы.

Задачи:
- интеграционное тестирование
- тестирование передачи файлов
- тестирование интеграции с кол-центром

---

## T9 — Запуск MVP
Основная цель: запустить решение в промышленную эксплуатацию.

Задачи:
- подготовка документации
- обучение пользователей
- запуск системы
